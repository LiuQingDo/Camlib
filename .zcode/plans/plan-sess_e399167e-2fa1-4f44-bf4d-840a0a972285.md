# AI 助手（媒体库问答 · 右侧抽屉 · 流式输出）

## Context

Camlib 已有云端 AI 基建（`AiConfig` 配置存 SQLite、`AiTransport` 传输层、自动打标、语义搜索、侧边栏 AI 区块），但缺少对话式入口。本次新增 **AI 助手**：右侧抽屉聊天面板，注入媒体库概况与当前浏览/选中/预览上下文，回答"去年十月拍了什么""帮我找海边的照片"这类问题；流式打字机输出；只读不写（可输出`[搜索]`标记让用户一键执行现有语义搜索）。

## 架构

```
前端抽屉 (main.ts) ──invoke("ai_chat", messages+context, Channel)──► lib.rs 命令
   ▲  Channel 逐段回传 delta                                        │
   └────────────────────────────────────────────────────────────── ai.rs
                                             1.收集上下文(库概况+缩略图) → 2.SSE流式请求 → 3.逐段 on_event.send
```

CSP 限制前端不能直连 API，全部走 Rust（与现有 AI 一致）。前端不传系统提示词，Rust 端统一构建。

## Rust 端

### 1. `src-tauri/src/ai.rs` — 传输层扩展
- `AiTransport` 新增 `chat_stream(config, messages: &[ChatMessage], image_jpeg, on_delta: &mut dyn FnMut(&str)) -> Result<String, AppError>`（返回完整内容）；`ChatMessage { role, content }`。`UreqTransport` 实现：POST `/chat/completions` 带 `"stream": true`，`into_reader()` 逐行读 SSE。
- 流式专用 Agent：`timeout_connect(15s)` + `timeout_read(60s)`（每次读的空闲超时，避免整体 180s 掐断长回复），复用 `authorization_header()` 与 `map_http_error()`。
- SSE 解析抽成纯函数 `parse_sse_chunk(line) -> Option<String>`（`data: {...}` → `choices[0].delta.content`，`[DONE]` 结束），便于单测。
- 新增 `build_chat_system_prompt(brief, context)`：中文系统提示词 + 库概况 JSON + 当前上下文 JSON + 今日日期锚点（仿 `query_parse_prompt`）+ 约定"想找照片时末行输出 `[搜索] 关键词`"。
- `run_chat()` 编排：`chat_ready()` 校验 → 收集库概况 → 有预览图则 `media::thumbnail_for_item` 取 512px JPEG 附到最后一条 user 消息 → 拼多轮 messages（系统提示 + 前端历史，截最近 16 条）→ 流式调用。

### 2. `src-tauri/src/db/mod.rs` — 新增 `library_brief()`
一条 SQL 返回 `LibraryBrief { total, photos, videos, lives, date_from, date_to, favorites }`；顶部标签复用现有 `list_tags`（按使用量取前 30，区分 AI 标签）。

### 3. `src-tauri/src/lib.rs` — 两个命令 + 状态
- `AiChatState { cancel: AtomicBool, busy: AtomicBool }` 托管进 app（仿现有 State 模式）。
- `ai_chat(messages, context, on_event: Channel<AiChatEvent>) -> AiChatResultDto { content, cancelled, error? }`：流中每段 `on_event.send(Delta)`；**先短暂取 Repository 锁收集上下文再释放**，不持锁做网络 IO；中途网络错误 → Ok(部分内容+error)，启动前错误 → Err(AppError)。
- `ai_chat_cancel()`：置 cancel 标志，worker 在段间检查。
- 注册进 `generate_handler!`（lib.rs:1833）。

## 前端

### 4. `src/api/ai.ts`
`AiChatMessageDto` / `AiChatContextDto` / `AiChatResultDto` 类型；`streamAiChat(messages, context, onDelta): Promise<AiChatResultDto>`（`import { Channel } from "@tauri-apps/api/core"`，channel.onmessage 分发 delta）；`cancelAiChat()`。

### 5. `src/main.ts`
- 状态：`aiChatOpen` / `aiChatMessages[]`（role/content/streaming/action）/ `aiChatBusy`，草稿用模块级 `let`。
- `renderAiChatDrawer()`：右侧固定抽屉（无遮罩，不挡网格点击），header（标题+清空+关闭）、上下文指示条（预览照片/筛选摘要）、消息列表、底部输入区（textarea 自动增高，Enter 发送 / Shift+Enter 换行，流式中变"停止"按钮）；挂进 `render()` 末尾浮层拼接处。
- **流式渲染纪律**：streaming 期间不调 `render()`，仿 `updateAiSingleProgress()` 直接 patch 当前气泡 `textContent` + 智能滚底（用户上滚则不拉）；done 后整次 `render()` 挂动作 chips，并重新聚焦输入框。
- `[搜索] xxx` 标记：正则提取，从正文剥离，渲染"🔍 执行语义搜索：xxx"chip，点击走现有 `commitSemanticSearch()`（main.ts:1361）。
- 上下文收集：发送时把当前筛选（search/kind/日期/标签名/评分/收藏）、预览项（mediaId/displayName/captureDate/aiCaption/aiTags…）、多选摘要打包为 context。
- 入口：侧边栏 `.ai-sidebar-actions` 加"✬ AI 助手"按钮；预览弹窗 AI 描述区加"问 AI 助手"小按钮。事件绑定进 `bindEvents()` AI 区块（main.ts:3589 附近）；Esc：无更高层 modal 时关闭抽屉。
- 未启用/未配置 AI：抽屉显示引导空态 + "去设置"（`openSettings("ai")`）。

### 6. `src/styles.css` + `src/liquid-glass.ts`
- 抽屉样式：复用 `--glass/--ink/--accent` 等 CSS 变量与现有按钮类，用户/助手气泡区分色，**必须补 `[data-theme="dark"]` 变体**。
- 左缘拖拽调宽（~380–520px），复用现有 `uiDialogSizes` 管线持久化（`aiChatDrawer` 键，零 Rust 改动）。
- 抽屉 selector 加入 liquid-glass.ts `TARGETS`；z-index 18（低于 modal 25，设置/预览可盖住它）。

### 7. 测试与文档
- `ai.rs` 单测：SSE 解析（多行 data/`[DONE]`/delta 提取）、`[搜索]` 标记提取、MockTransport 流式；`cargo test`。
- 顺手更新 `docs/architecture.md` 命令清单。

## 验证
1. `pnpm build`（tsc 通过）+ `cd src-tauri && cargo test`。
2. `pnpm tauri dev` 手测：未启用 AI → 引导空态；启用后侧边栏开抽屉，提问观察流式逐字输出；流式中点"停止"；问"帮我找海边的照片"→ 出现搜索 chip → 点击后网格按语义搜索刷新；预览弹窗打开时提问验证图片上下文；清空对话、Esc 关闭、拖宽后重启宽度保留；浅色+深色主题各过一遍。
