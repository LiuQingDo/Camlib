# Camlib 术语表

> 目的：同一个东西在界面、文档、代码注释里只用一种叫法。
> 用法：改任何用户可见文案前先查这张表；新增概念时补一行。
> 最后更新：2026-11-23

---

## 1. 核心概念

| 概念                              | 统一叫法       | 不要用                      | 说明                                                                                         |
| --------------------------------- | -------------- | --------------------------- | -------------------------------------------------------------------------------------------- |
| 用户指定的原始照片目录            | **媒体库**     | 库、目录、文件夹、根目录    | 可以注册多个媒体库；"库"只在代码与本文里做简称                                               |
| 把相机卡里的文件复制进媒体库      | **导入**       | 备份、复制、同步            | 「备份」在日常语境里暗示"另一份拷贝"，而这里的动作就是导入；历史文档中的 "backup" 指同一件事 |
| 遍历媒体库、更新索引              | **扫描**       | 增量扫描、刷新、rebuild     | 默认行为就是增量；需要强调时写「扫描（增量）」                                               |
| 清空索引并重新遍历                | **重建索引**   | 全量扫描、全量重建、rebuild | 破坏性动作，必须出现在危险确认里                                                             |
| 文件不在原位置（盘拔了 / 被移动） | **离线**       | 缺失、missing、丢失         | 「丢失」暗示数据丢了，实际只是路径不通                                                       |
| 从 Camlib 中移除媒体              | **移入回收站** | 删除、清除                  | 文件进 Windows 回收站，索引标记；不用"删除"以免用户以为永久销毁                              |
| 索引数据库与缩略图所在位置        | **存储**       | 缓存目录、应用目录          | 「缓存」只指缩略图缓存这一项                                                                 |
| 相机卡根目录下的照片文件夹        | **DCIM**       | 相机目录                    | 专有名词，保留英文                                                                           |

## 2. 界面区域

| 区域                           | 统一叫法       | 不要用                |
| ------------------------------ | -------------- | --------------------- |
| 左侧导航栏                     | **侧栏**       | 边栏、导航栏、sidebar |
| 顶部一行（标题 + 搜索 + 扫描） | **顶栏**       | 头部、header、导航条  |
| 筛选条件的横向条               | **筛选栏**     | 工具条、filter bar    |
| 网格上方的批量操作区           | **批量工具栏** | 选择栏、selection bar |
| 右侧滑出的导入面板             | **导入面板**   | 备份面板、备份预览    |
| 两个及以上媒体被选中时的状态   | **已选 N 项**  | 选中 N 个、N selected |

---

## 3. 状态与反馈

| 概念                             | 统一叫法          | 说明                                           |
| -------------------------------- | ----------------- | ---------------------------------------------- |
| 需要用户处理、不会自动消失的提示 | **错误条**        | 常驻顶部，可关闭；不是 toast                   |
| 长任务的进度（扫描/导入/打标）   | **任务胶囊**      | 顶栏右侧，可展开、可后台                       |
| 操作结果的短提示                 | **提示（toast）** | 4 秒消失，可带一个动作                         |
| 删除/批量操作可回退              | **撤销**          | 只在真的能撤销时使用；不能撤销就写「不可撤销」 |

---

## 4. 技术词汇的处理

技术词汇（卷 ID、扫描代数、schema 版本、`%APPDATA%` 路径、ffmpeg、原子提交）**不出现在主界面**，统一收进「设置 → 关于与诊断」，需要时以 `?` 或折叠说明呈现。

例外：错误详情里的原始 message 可以保留技术细节，但必须折叠在「详情」之下。

---

## 5. 代码里的对应关系

| 术语       | 代码标识                                |
| ---------- | --------------------------------------- |
| 媒体库     | `library` / `libraryRoot`               |
| 导入       | `backup`（历史命名，不改）、`backupRun` |
| 扫描       | `scan` / `scanRun` / `scanGeneration`   |
| 重建索引   | 全量 `scan`（`full: true`）             |
| 离线       | `scan_state = 'missing'`、`scanState`   |
| 移入回收站 | `deletion` / `recycle`                  |
| 收藏       | `favorite`                              |
| 评分       | `rating`（1–5，0 = 未评分）             |
| 标签       | `tag`（用户标签）/ `ai_tag`（AI 标签）  |

> 代码标识不强制改名（`backup` 已经贯穿 Rust 与前端，改名收益低于风险）；**只要求用户可见文案与本文一致**。
