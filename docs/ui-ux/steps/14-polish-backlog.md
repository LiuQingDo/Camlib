## 1. 怎么用这份清单

这是一张**可挑选的菜单**，不是一次会话要做完的任务。规则：

1. **按表格顺序取**（前面的收益更高）。
2. **一条一个 commit**，commit message 带诊断编号，例如 `polish(card): 2.1 卡片标题降级为时:分 + 评分`。
3. **单条改动超过 150 行就停**，说明它不该算 P2，回到 `README.md` 单独开一步。
4. 做完在 `diagnosis.md` 对应行末标 `✅ 已修（步骤 14）`，方便下一轮别重复提。

## 3. 实现要点（挑几条容易做歪的）

1. **2.1 卡片信息档位**：不要只做"降级"，要做成设置项。摄影用户里有一半人希望看到文件名（他们靠文件名找图），默认可以是「标准」而不是「极简」。
2. **2.3 密度与 `Ctrl+滚轮`**：`Ctrl+滚轮` 在预览里已经是缩放，在网格里才调密度——**按上下文分派**，不要全局劫持。
3. **2.6 滚动位置**：只有「筛选条件变化」保留位置，`06` 的"重置全部"仍回顶部；两者不要混。
4. **11.7 插画**：用 `icons.ts` 同一套 24 网格 + 1.5 描边，放大到 96px 时把描边改成 1（`vector-effect: non-scaling-stroke`），否则看起来像毛边。
5. **13.5 reduced-motion**：不要粗暴地 `* { animation: none }`，会把 loading spinner 也停掉；只针对 `transition` 与位移类 `animation`。
6. **14.4 下一步动作**：动作必须真的能到达（`查看合并结果` 要能定位到新文件），做不到就不加。
