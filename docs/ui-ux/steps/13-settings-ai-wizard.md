## 4. 实现要点

1. **分区收敛的判据是"用户要回答什么问题"**：我的库怎么样（库）→ 占了多少空间（存储）→ 怎么把照片弄进来（导入）→ AI 怎么配（AI）→ 程序行为（系统）→ 出问题看什么（关于与诊断）。
2. **搜索不要做成全文搜索**。设置项总数不足百条，静态索引表 + 包含匹配足够；关键是「点结果能跳过去并高亮」，否则搜索只是过滤器。
3. **危险动作的"可撤销"必须是真的**。清理离线条目可以通过重新扫描恢复（真实）；删除标签不可撤销（真实）；全量重建耗时但无损（真实）。**不要写"可撤销"来安抚用户**。
4. **AI 向导的验证时机**：填完 Key 立即验证（调 `ai_test_connection` 或列模型接口），失败就地提示，不让用户"保存后才发现 Key 错了"。
5. **向导不要做成全屏 step-by-step 遮罩**：在 AI 分区内用三段式卡片（当前步展开、其余折叠），用户随时能看到自己在哪、能回退。
6. **旧设置偏好兼容**：`settingsSection` 可能存在旧值（`index` / `thumbnails` / `backup`），读取时映射到新分区，不要让人打开设置看到空白。
7. **术语表先落地再改文案**：先写 `glossary.md`，再按表替换，否则一边改一边又新增叫法。
