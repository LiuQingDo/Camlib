# Camlib 项目需求

> 版本：v0.2（对齐已实现应用）  
> 整理日期：2026-09-12  
> 项目定位：面向个人相机媒体备份与管理的 Windows 桌面应用  
> 实现现状见 `docs/architecture.md`；第一版验收项已基本落地。

## 1. 项目目标

在同一个桌面窗口中完成：

- 相机媒体导入与备份
- 媒体库浏览和预览
- 搜索、筛选和排序
- 收藏、标签、评分及其他管理操作
- 安全删除与备份状态查看

应用不替代原始媒体存储设备。原始照片和视频仍由用户指定的媒体库目录保存。

## 2. 存储策略（已确认）

项目源码、构建缓存、索引数据库和缩略图缓存放在电脑内置 SSD；原始媒体放在用户指定的媒体盘（常见为外接盘）。

要求：

1. 首次启动允许用户选择媒体库根目录；路径可在设置中修改。
2. 外接盘未连接时应用仍可启动，并明确提示媒体库不可用。
3. 不只依赖盘符；记录路径并结合卷标/磁盘唯一标识识别外接盘。
4. 原始媒体默认只读；删除、移动等破坏性操作由后端执行并经安全校验。
5. 索引和缩略图属于可重建数据，损坏后不影响原始媒体。

## 3. 历史原型（迁移参考）

实现前存在 PowerShell 备份脚本、Python 静态清单/本地 HTTP 服务、浏览器查看器等原型。它们提供了日期分类、实况配对、缩略图、连拍、收藏、回收站删除、备份日志等行为参考。

当前仓库**不依赖**这些原型运行时组件；正式索引以 SQLite 与增量扫描为准。原型文件路径与盘点数字不再维护。

## 4. 功能需求

### 4.1 媒体库浏览（P0）

- 按年份、月份、日期浏览；查看全部、照片、视频、实况照片。
- 缩略图网格与大图/视频预览；上一项/下一项、方向键、Esc。
- 视频流式播放，不把整个文件加载到内存。
- 显示文件名、日期、大小、尺寸、视频时长等信息。
- 支持不同缩略图密度。

### 4.2 搜索和筛选（P0）

- 按文件名搜索；按媒体类型、日期/日期范围筛选。
- 按最新、最早、文件名排序；支持连拍筛选。
- 支持收藏、标签、评分筛选与组合（标签/评分见 4.5）。

### 4.3 索引和扫描（P0）

- 启动时检查媒体库变化；优先增量扫描，不重复处理未变化文件。
- 新文件自动入库；移除/移动后索引状态可识别。
- 扫描、缩略图、元数据读取显示进度；支持取消。

### 4.4 相机备份（P0）

- 自动发现含 `DCIM` 的可移动磁盘；用户确认源盘与目标媒体库。
- 预览待导入数量、总大小、重复项、冲突项；检查目标盘剩余空间。
- 按拍摄日期整理到：`年\月\日期\媒体类型`。
- 复制后校验文件大小；失败记录原因并支持重试。
- 显示复制进度、速度、剩余时间和最终汇总。
- 不修改或删除相机中的文件；备份完成后自动刷新索引。
- `.dng` / `.lrv` 等忽略扩展名在设置中配置。

### 4.5 收藏、标签与评分（P0/P1）

- 收藏、标签、评分持久化在 SQLite；重扫后不丢失；不依赖 `localStorage`。
- 标签：创建/重命名/删除、批量打标、按标签筛选。
- 评分：1–5 星，可改可筛（≥N 星或指定星级）。

### 4.6 安全管理（P0）

- 支持单选/多选；实况照片作为一个逻辑项，同时处理照片与视频。
- 删除默认移入 Windows 回收站，不是永久删除。
- 批量删除前显示数量与文件摘要；破坏性操作二次确认。
- 后端校验所有路径，禁止越过媒体库根目录操作文件。
- 操作失败时保留清晰错误信息和日志；支持部分成功结果展示。

### 4.7 设置和状态（P1）

- 设置媒体库根目录、缩略图缓存位置、导入忽略类型与冲突策略。
- 显示最近备份时间、成功/失败数、剩余空间。
- 显示媒体库连接状态与索引更新时间。
- 提供重新扫描、重建缩略图、重建索引操作。

### 4.8 系统集成（P1）

- Windows 桌面通知；最小化到托盘/后台继续备份。
- 从媒体项打开所在文件夹。
- 单实例运行，避免多进程同时修改索引。

## 5. 技术方案

### 5.1 应用框架

- Tauri 2
- 前端：Vanilla TypeScript + HTML/CSS
- 后端：Rust
- 构建工具：Vite
- 数据库：SQLite

### 5.2 前端与后端职责

前端负责界面状态、筛选、网格渲染、预览交互和进度展示；后端负责文件扫描、路径校验、复制、删除、缩略图生成、数据库读写和系统能力调用。

长时间任务不得阻塞界面，通过 Tauri Channel / 事件向前端发送进度；结果持久化到 runs 表。

### 5.3 数据模型

核心表：`libraries`、`media_items`、`media_files`、`favorites`、`tags`、`media_tags`、`media_ratings`、`scan_runs`、`backup_runs`、`backup_items`、`deletion_logs`、`app_settings`。

实况照片是一个 `media_item`，关联照片与视频两个 `media_files`。表结构以 `docs/data-model.md` 与 `src-tauri/src/db/migrations/` 为准。

### 5.4 缩略图和视频处理

- 缩略图放 SSD 缓存目录；原图/原视频不复制到应用目录。
- 以路径、大小、修改时间等判断是否需要更新缓存。
- 视频缩略图使用 ffmpeg；查找顺序：`CAMLIB_FFMPEG_PATH` → 打包资源 → PATH/WinGet。

## 6. 第一版验收标准

1. 启动应用并选择媒体库目录。
2. 看到按日期组织的媒体缩略图。
3. 点击缩略图查看照片或播放视频。
4. 搜索文件名并按类型、日期筛选。
5. 收藏媒体，关闭应用后再次打开收藏仍在。
6. 从相机可移动盘导入新媒体并看到实时进度。
7. 断开媒体盘后应用不崩溃，并提示媒体库不可用。
8. 删除媒体时只进入 Windows 回收站，且不会操作媒体库之外的文件。
9. 重启应用后索引、缩略图和用户操作状态保持正常。

发布前完整检查见 `docs/release-checklist.md`。
